# 外部证据选择评测

仓库现在包含一套可复核、标签隔离的广域问答回答侧证据选择评测。

## 测量内容

系统获得官方中文阅读理解上下文和问题，必须从上下文中选择一条完整证据句。只有当结果的字节范围和 SHA-256 能精确指向原上下文时，引用才算有效；分数统计官方金答案是否出现在所选证据句中。

这是外部上下文证据选择基准，不测量随机 20k Wikipedia 索引检索、自由生成、事实裁定、长期记忆或通用对话。

## 冻结来源

- CMRC2018：官方仓库 commit `c0eb1b6ba219847457e6af3180da722bbeb656af`，CC BY-SA 4.0。
- DRCD：官方仓库 commit `b944790de5af02c5fbb7cd9cb1473d27d169eebf`。仓库没有机器可识别的独立许可文件，但 README 明示其 Wikipedia 改编内容按 CC BY-SA 3.0 发布。

六个来源文件的 SHA-256、解析异常、划分规则和 artifact 身份记录在 K 盘冻结 manifest 中；来源副本和评测 payload 不提交到本仓库。

## 划分和隔离

冻结包包含 200 道 dev 和 300 道 held-out，两个来源各占 100/150 道。先用规范化标题哈希确定标题域所属 split，再用题目 SHA-256 稳定取样；两个 split 的标题域交集为 0。questions JSONL 不含金答案，labels 单独存放，只有评分阶段读取。

## 正式结果

算法、划分、分母和阈值在开发阶段后冻结。held-out 只运行一次：

| 指标 | 结果 |
| --- | ---: |
| 题数 | 300 |
| 精确引用有效 | 300/300（100%） |
| 金答案出现在所选证据句 | 234/300（78%） |
| CMRC2018 | 105/150（70%） |
| DRCD | 129/150（86%） |
| 状态 | 在预先声明的 70% 证据命中门上 PASS |

正式 aggregate SHA-256：`82bc0c5083fe5c9ce4e8f1a3bfee756e3681fbd28ee0756e0e6bbefb9957c96d`。

这是有界的抽取式能力结果：它证明回答侧选择器能依据外部问题表述，在冻结来源中选出可审计证据句；不代表广域检索、开放式语言理解、通用智能或断奶已经完成。

## 复现

取得固定来源 checkout 和 K 盘冻结包后，严格分两阶段运行 `predict` 与 `score`。预测阶段不能读取 labels，评分阶段会拒绝来源字节、题目 inventory、上下文 span、哈希或重复发布发生变化。K 盘可再生产 payload 在保留重建合同和紧凑 receipt 后允许清理。
