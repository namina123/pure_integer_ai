## 删除/迁移前硬门槛

任何目录实际删除前，必须同时满足：

1. 当前 OS 进程、训练控制文件、发布 manifest 和测试路径均无读取依赖；
2. 已保留官方 URL/DOI、版本或 commit、许可证、源 hash、转换参数、课程 hash 与 receipt；
3. 已对重复 artifact 做内容 SHA 对比，并明确哪个目录是 canonical；
4. 对非 Apache/CC-BY/项目自有来源保留许可证证据，禁止把删除后的来源重新接入公开训练；
5. 先移动到明确的 K 盘隔离归档并验证可恢复，再删除；不得使用 `git clean`、递归删除工作区或覆盖 canonical SQLite；
6. 删除后更新本文件和长期进度，记录释放字节数与可恢复位置。
